# WEB-PROJECT

1. โหลดไฟล์ zip  
2. รันตัว Database ในไฟล์ sql (sec2_gr3_database.sql) 
3. สร้างไฟล์ .env ใน folder "sec2_gr3_ws_src" (ใช้ข้อมูลตัวเอง) PORT= 8000 DB_HOST= ? DB_USER=? DB_PASS=? DB_NAME= sec2_gr3_database  
4. เปิด Terminal(cmd) 2 อัน
5. ในแต่ละ Terminal ให้ cd ไปที่ Folder "sec2_gr3_fe_src" และ "sec2_gr3_ws_src"
6. npm install express ,nodemon ,mysql2 ,body-parser ,cors ,dotenv ทั้งสอง Terminal  
7. npm start ทั้งสอง Terminal
8. หน้า landing จะเด้งขึ้นมาอัตโนมัติ
9. สำหรับหน้า Login (USERNAME ADMIN : superadmin 
                    PASSWORD ADMIN : superpass)
